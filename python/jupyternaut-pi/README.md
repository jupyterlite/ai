# jupyternaut-pi

The [pi coding agent](https://pi.dev) in JupyterLab and JupyterLite, in the
browser: a chat persona next to Jupyternaut, and the agent of the `pi` terminal
command of `jupyternaut-terminal`.

## Install

```bash
pip install jupyternaut-pi
```

Select **Pi** in the persona menu of a chat. Run **Pi: Set a Model Provider API
Key** from the command palette to add a key.
